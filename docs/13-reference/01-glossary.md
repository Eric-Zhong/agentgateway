# 术语表

- **IR**：运行时统一内部表示。
- **xDS**：控制面传输协议；本项目使用自有 resource 类型。
- **LLM**：大语言模型及其 provider/model 接入。
- **MCP**：Model Context Protocol，工具与外部数据接入协议。
- **A2A**：Agent-to-Agent 通信协议。
- **CRD**：Kubernetes CustomResourceDefinition。
- **CEL**：Common Expression Language，用于策略表达式。
- **E2E**：端到端测试。
