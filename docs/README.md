# 项目工程文档

本目录按软件工程生命周期组织 agentgateway 的需求、领域、架构、设计、接口、测试、部署、运维、安全、开发、发布与参考资料。文档内容以仓库代码、配置、测试、CI 和现有架构说明为主要证据来源。

## 阅读路径

1. 从 [[00-index/01-document-map]] 了解全局导航与证据边界。
2. 从 [[02-requirements/01-product-scope]] 和 [[03-domain/01-domain-overview]] 了解系统目标与领域模型。
3. 从 [[04-architecture/01-system-context]]、[[05-design/01-runtime-design]] 了解实现结构。
4. 按 [[07-testing/01-test-strategy]]、[[08-deployment/01-deployment-models]]、[[09-operations/01-operations-handbook]] 执行验证与运行。
